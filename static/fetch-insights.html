How to read these numbers

A listing operation is a single-page fetch call, excluding internal HTTP retries, detail requests and image requests. Returned and admitted occurrences may differ; new and existing status is determined before admission to the database.

Positive rate = positive ÷ (positive + negative). Neutral, duplicate updates and unknown outcomes are listed separately; no feedback does not mean negative. Only the latest feedback created after the query association was first recorded is counted; undo recalculates the results. “Visible and positive” is the intersection of galleries with an actual visibility receipt after the query association and galleries whose latest feedback is positive. It does not establish that viewing preceded feedback or imply causation.

Multiple queries can discover the same gallery, so rows cannot be added together or used to prove that a query caused feedback. Historical inference comes from the old source_query field and indicates coverage only; historical cost and outcomes are unknown. Rates based on small samples should not be compared directly.
