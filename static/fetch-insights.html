如何解读这些数字

一次列表操作指一次单页采集调用，不包括内部 HTTP 重试、详情或图片请求。返回次数与入库次数可能不同；新增和重复以入库前是否存在为准。

好评率 = 好评 ÷（好评 + 差评）。中立、重复更新和未知均单列，未反馈不算差评。只统计首次记录该查询关联后产生的最新反馈；撤销会重新计算。“可见且好评”是查询关联后有实际可见回执、且最新反馈为好评的交集，不表示先看后评或因果关系。

同一画廊可由多个查询发现，因此各行不能直接相加，也不能证明某查询导致了反馈。历史推断来自旧 source_query 字段，仅提示覆盖，没有历史成本或收益。样本少的比率不宜直接比较。

暂无采集记录。启用后执行采集，新的列表操作会开始积累数据。
